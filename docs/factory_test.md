# T-Deck-Pro 工厂测试 SOP

## 1. 文档信息

- 适用产品：T-Deck-Pro
- 适用机型：A7682E 4G 版、PCM5102A 音频版
- 适用工厂软件：`v2.4-260320`
- 依据版本：
  - 软件版本：`UI_T_DECK_PRO_VERSION = v2.4-260320`
  - 硬件版本显示：`BOARD_T_DECK_PRO_VERSION = v2.0-250915`
- 依据文件：
  - `examples/factory/factory.ino`
  - `examples/factory/ui_deckpro.cpp`
  - `examples/factory/ui_deckpro_port.cpp`
  - `firmware/README.md`

## 2. 目的

用于产线对 T-Deck-Pro 整机进行出厂功能确认，确保主控、显示、输入、供电、LoRa、GPS 以及机型分支模块工作正常。

本文档只覆盖测试流程，不展开烧录工具和烧录步骤。

## 3. 前置条件

开始测试前，默认满足以下条件：

- 设备已烧录当前工厂固件。
- 设备已烧录 `spiffs.bin` 文件系统。
- 电池已安装并连接。
- 需要测试 `A7682E` 时，必须接电池，不能只靠 USB 供电。
- 测试 `GPS` 时，设备需放在室外或开阔窗口附近。
- 测试 `LoRa` 时，需准备另一台可正常工作的 LoRa 对端设备。
- 测试 `PCM5102A` 时，需准备耳机或音频夹具。
- 测试 `SD Card` 时，需插入可识别的 TF 卡。
- 测试 `A7682E` 时，需安装天线并插入可用 SIM 卡。

## 4. 产线辅具

- USB 数据线 1 根
- 标配电池 1 块
- TF 卡 1 张
- LoRa 对测设备 1 台
- 4G 天线 1 根
- 可用 SIM 卡 1 张
- 耳机或音频夹具 1 套

## 5. 界面术语

本文档直接沿用工厂 UI 中的英文页面名和状态字样：

- `Test`
- `Input`
- `GPS`
- `Battery`
- `A7682E`
- `PCM5102A`
- `Motor`
- `Sleep`
- `Shutdown`
- `PASS`
- `----`

说明：

- `PASS` 仅表示该模块初始化通过。
- `PASS` 不等于整项功能已完成验证，仍需进入对应页面做人工确认。
- `----` 表示该项未通过初始化，或当前机型不匹配。
- 音频版主菜单入口当前可能显示为 `PCM5012`，实际对应 `PCM5102A` 音频测试。
- 主菜单入口为 `Input`，进入后页面返回标题可能显示为 `Other`。

## 6. 版本差异说明

### 6.1 T-Deck-Pro V1.1

- 工厂程序可检测到 `DRV2605`。
- `Motor` 页面按正常流程执行振动测试。
- EPD 使用硬件复位模式。

### 6.2 T-Deck-Pro V1.0

- 工厂程序会进入 EPD 兼容模式，面板复位脚不参与刷新。
- 若下载工厂固件后屏幕仍异常不显示，先断开电池约 10 秒，再重新接入电池后复测。
- `Motor` 页如无明显振动，不作为 V1.0 版本的单独放行依据，优先以 `Test` 页和其它功能页结果判定。

## 7. 测试总流程

建议按以下顺序执行：

1. 外观与开机初检
2. `Test` 页快速判定
3. `Input` 页验证触摸、键盘、陀螺仪
4. `GPS` 页验证定位与时间
5. `Battery` 页验证充电与电池信息
6. `Lora` 页进行收发联测
7. `Motor` 页验证振动
8. 执行机型分支测试
9. `Sleep` / `Shutdown` 收尾测试

## 8. 详细测试步骤

### 8.1 外观与开机初检

操作：

- 检查外观，无缺件、破损、明显装配不良。
- 确认屏幕、键盘、接口、天线座、电池座无异常。
- 上电开机，观察是否能进入工厂主界面。
- 检查屏幕是否能正常刷新，是否能看到版本信息与菜单图标。

预期结果：

- 设备正常开机进入工厂界面。
- 屏幕显示清晰，无整屏不刷新、长时间卡死、全白或全黑。
- 主菜单中可看到 `Lora`、`Setting`、`GPS`、`Test`、`Battery`、`Input`、机型分支页、`Shutdown`、`Sleep`、`Motor`。

不通过判定：

- 无法开机。
- 屏幕不显示或刷新异常。
- 主菜单显示错乱或无法进入。

### 8.2 `Test` 页快速判定

操作：

- 在主菜单进入 `Test` 页面。
- 逐项检查状态。

公共项应为 `PASS`：

- `Lora`
- `Touch`
- `BQ25896`
- `BQ27220`
- `SD Card`
- `Keypad`
- `GPS`
- `BHI260AP`
- `INK_SCREEN`

机型分支项要求：

- 4G 版：`A7682E = PASS`，`PCM5102A = ----`
- 音频版：`PCM5102A = PASS`，`A7682E = ----`

预期结果：

- 公共模块全部显示 `PASS`。
- 机型分支项仅有一个模块显示 `PASS`。

不通过判定：

- 任一公共模块显示 `----`。
- `A7682E` 和 `PCM5102A` 同时 `PASS` 或同时 `----`。

备注：

- `Test` 页只是初始化结果，不替代后续页面验证。

### 8.3 `Input` 页验证

操作：

- 在主菜单进入 `Input` 页面。
- 用手指在屏幕上多点、多区域触摸。
- 依次按下多颗键盘按键，观察字符回显。
- 轻微晃动设备，观察陀螺仪数值变化。

预期结果：

- 触摸后 `Touch: x: xxx | y: yyy` 坐标发生变化。
- 键盘输入区持续追加按键字符。
- `gyros_x / gyros_y / gyros_z` 数值随晃动变化。

不通过判定：

- 触摸坐标始终不变。
- 键盘按下无回显。
- 陀螺仪数值长时间不变化。

### 8.4 `GPS` 页验证

操作：

- 将设备移至室外或开阔环境。
- 进入 `GPS` 页面。
- 持续观察页面刷新。
- 首次定位允许等待。

预期结果：

- `Latitude`、`Longitude` 有有效数值更新。
- `year`、`month`、`day`、`time` 可以刷新。
- `vsat` 大于 0。
- 页面内容约每 3 秒刷新一次。

判定建议：

- 首次定位建议等待不超过 5 分钟。
- 若 5 分钟内 `vsat` 始终为 0，或经纬度与时间均不更新，可判定 `GPS` 失败。

不通过判定：

- 长时间无卫星。
- 时间、日期、经纬度始终不刷新。

### 8.5 `Battery` 页验证

操作：

- 进入 `Battery` 页面。
- 先查看 `BQ25896` 子页，再查看 `BQ27220` 子页。
- 记录插入 USB 前状态。
- 插入 USB，等待页面刷新。
- 再拔出 USB，确认状态恢复。

#### 8.5.1 `BQ25896` 子页

重点字段：

- `Charging`
- `VBUS`
- `VSYS`
- `VBAT`
- `VOLT Target`
- `Charge Curr`
- `Prechg Curr`
- `CHG ST`
- `VBUS Status`

预期结果：

- 插入 USB 后，`VBUS` 有有效电压值。
- 充电状态显示为 `Charging` 或等效充电状态。
- `VBUS Status`、`CHG ST` 与插拔动作一致变化。

#### 8.5.2 `BQ27220` 子页

重点字段：

- `VBUS ST::`
- `Charing ST:`
- `Battery ST:`
- `Voltage`
- `Current`
- `Temperature`
- `Cap Remain`
- `Cap Full`
- `Cap Percent`
- `CapHealth`

预期结果：

- 插入 USB 后，`VBUS ST::` 显示 `Connected`。
- 拔出 USB 后，`VBUS ST::` 显示 `Disonnected`。
- 插入 USB 后，`Charing ST:` 显示 `Charging` 或 `Finsish`。
- 拔出 USB 后，`Charing ST:` 显示 `Discharge`。
- `Voltage`、`Current`、`Cap Percent`、`Temperature` 为有效数值。

不通过判定：

- USB 插拔前后状态无变化。
- 电池信息页为空白、固定不变或明显异常。

### 8.6 `Lora` 页联测

操作：

- 在主菜单进入 `Lora`。
- 先进入 `- Lora Setting`，确认与对端设备一致：
  - `Freq`
  - `Band`
  - `Power`
- 返回后进入 `- Auto Test`。
- 默认模式为 `Send`。
- 准备两台设备时：
  - A 机保持 `Send`
  - B 机点击模式按钮切换到 `Recv`
- 观察发送与接收日志。

预期结果：

- 发送端周期性显示 `send-> DeckPro #x`。
- 接收端能显示 `recv-> ... [RSSI]`。
- 可正常在 `Send` 和 `Recv` 之间切换。

不通过判定：

- 无法切换模式。
- 接收端长时间收不到数据。
- 显示内容异常或 RSSI 不显示。

备注：

- 若使用非工厂默认参数，双方参数必须保持一致。
- 默认程序会周期性自动发包，无需手工输入内容。

### 8.7 `Motor` 页验证

操作：

- 在主菜单进入 `Motor`。
- 手持设备感受振动变化。

预期结果：

- 设备约每 2 秒切换一次振动效果。
- 可以明显感知到振动存在。

不通过判定：

- V1.1 版本下完全无振动。
- 振动异常微弱、时有时无或明显失真。

备注：

- 本项对 V1.1 为正常必测项。
- V1.0 仅作参考，不单独作为放行依据。

### 8.8 机型分支测试

#### 8.8.1 A7682E 4G 版

操作：

- 确认 `Test` 页显示 `A7682E = PASS`。
- 主菜单进入 `A7682E` 页面。
- 依次验证以下功能：
  - `A7682 Audio`
  - `Call test`
  - `AT test`

##### A7682 Audio

操作：

- 点击 `A7682 Audio`。

预期结果：

- 模块可执行语音播报测试。

##### Call test

操作：

- 点击 `Call test`。
- 在拨号界面输入号码。
- 点击呼叫键发起拨号。
- 点击 `Hang up` 挂断。

预期结果：

- 数字键盘可输入号码。
- 模块可发起拨号。
- 可正常挂断。

##### AT test

操作：

- 点击 `AT test`。
- 打开串口工具，波特率设为 `115200`。
- 通过串口向 A7682E 发送 AT 指令验证。

预期结果：

- 串口通道正常。
- 模块能响应 AT 指令。

不通过判定：

- 无法拨号。
- 串口无响应。
- A7682E 页面功能不可进入或不可操作。

#### 8.8.2 PCM5102A 音频版

操作：

- 确认 `Test` 页显示 `PCM5102A = PASS`。
- 主菜单进入 `PCM5102A` 页面。
- 点击 `PCM5102 Audio`。
- 通过耳机或音频夹具监听。

预期结果：

- 设备可播放 SPIFFS 内测试音频。
- 可清晰听到音频输出。

不通过判定：

- 无声。
- 声音断续、明显失真或噪声过大。

备注：

- 若无 `spiffs.bin`，音频测试可能失败。

### 8.9 `Sleep` 测试

操作：

- 在主菜单点击 `Sleep`。

预期结果：

- 设备会立即进入深度休眠。
- 按下 `BOOT` 键后可唤醒。

不通过判定：

- 点击后无法进入休眠。
- 休眠后按 `BOOT` 键无法唤醒。

备注：

- `Sleep` 页面无确认弹窗，点击后即执行休眠。

### 8.10 `Shutdown` 测试

#### USB 供电场景

操作：

- 保持 USB 已连接。
- 点击 `Shutdown`。

预期结果：

- 屏幕显示提示：接 USB 时不可关机。
- 设备不会关机。

不通过判定：

- 接 USB 时仍直接关机。

#### 纯电池供电场景

操作：

- 拔掉 USB，仅保留电池供电。
- 点击 `Shutdown`。

预期结果：

- 设备进入关机流程。
- 进入页面后约 2 秒自动关机。

不通过判定：

- 纯电池供电时无法关机。

## 9. 放行判定

### 9.1 判定为 PASS

满足以下条件可判定整机通过：

- 外观与开机正常。
- `Test` 页公共项全部 `PASS`。
- 机型分支项判定正确。
- `Input`、`GPS`、`Battery`、`Lora`、`Sleep`、`Shutdown` 通过。
- V1.1 版本 `Motor` 通过。
- 4G 版 `A7682E` 测试通过，或音频版 `PCM5102A` 测试通过。

### 9.2 判定为 FAIL / 返修

出现以下任一情况可判定不通过：

- 无法开机或屏幕异常。
- 任一公共模块初始化失败。
- 机型识别不正确。
- 关键功能页无法进入或无法完成测试。
- 休眠、关机、LoRa、GPS、供电管理测试失败。

## 10. 常见异常处理

### 10.1 屏幕不显示或刷新异常

- 对 V1.0 设备，先断开电池约 10 秒，再重新接入后复测。
- 重新确认已写入工厂固件和 `spiffs.bin`。

### 10.2 4G 测试失败

- 先确认电池已接入。
- 确认 SIM 卡、天线安装正确。
- 串口波特率使用 `115200`。

### 10.3 音频测试失败

- 确认设备为 PCM5102A 音频版。
- 确认已写入 `spiffs.bin`。
- 更换耳机或音频夹具复测。

### 10.4 GPS 无法定位

- 移至室外或更开阔位置。
- 保持静置，连续等待。
- 超过 5 分钟仍无有效卫星可判不通过。

### 10.5 LoRa 无法联测

- 确认对端设备正常。
- 确认双方 `Freq`、`Band`、`Power` 一致。
- 一台设为 `Send`，另一台设为 `Recv`。
