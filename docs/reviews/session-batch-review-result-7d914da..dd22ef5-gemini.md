## 1. 前置处置项核销复核（逐条反例攻击）

按 `review_guide.md` §0 原则 8，对前置三份 ds4 结果保留项核对代码与时序：

### 1.1 L1 (P2)：LevelTest `s_enter_pending` 跨 QUIZ 存活污染 RESULT 页——✅ 核销成立
- **原缺陷**：在非 QUIZ 页面置位后，若进入测验，历史缓冲的 Enter 一直未清，测试提交返回 RESULT 页面瞬间自动触发，导致分数页被直接刷成新测试 Q1。
- **复核代码**：走查 `examples/pda2/ui_leveltest.cpp`：
  1. `leveltest_keyboard_poll()`（`:575`）：缓冲置位严格收紧至 `s_lt_page == LT_PAGE_HOME`，RESULT/HISTORY 页面在飞请求不再响应 Enter 缓冲；
  2. `lt_render_question()`（`:402`）：进入首题渲染时无条件清零 `s_enter_pending = false;`。
- **反例攻击**：在 HOME 页连续敲击两次 Enter（第一次触发测试拉取，第二次进入缓冲）；测试请求返回进入第一题，`lt_render_question` 立即将 `s_enter_pending` 抹平；测验连续作答至最后一题提交，提交完成进入 RESULT 页面时 `s_enter_pending` 必然为 false。反例击穿失败，闭环成立。

### 1.2 N1 (P2)：NewDict 详情页例句/词块汉字隐形——✅ 核销成立
- **原缺陷**：例句与词块 label 使用普通 `lv_label_set_text`，在 EPD 默认 ASCII 字体下汉字被滤除或留白。
- **复核代码**：走查 `examples/pda2/ui_newdict.cpp`：
  - 双语例句 `s_d_ex_lab`（`:516`）与词块/关联 `s_d_tail_lab`（`:529`）全部切为 `nd_set_text`；
  - `nd_set_text` 内部检测 `nd_has_cjk()`，只要含多字节 UTF-8 字符无条件切换至 `&Font_Hanzi_16`，纯英文字符保持 `Font_Mono_Bold_15`。
- **反例攻击**：详情页包含英文词组与中文释义双语混排，`nd_has_cjk` 返回 true，成功加载 16 点阵汉字字库，汉字正常显影。核销成立。

### 1.3 F1′ (P3)：WiFi 扫描快径漏掉 `esp_wifi_scan_stop()`——✅ 核销成立
- **复核代码**：走查 `examples/pda2/ui_deckpro.cpp:3383`：在 `if (WiFi.scanComplete() != WIFI_SCAN_RUNNING)` 快径释放分支中补充了 `esp_wifi_scan_stop();`，阻断了 Arduino 6s 超时清除 SCANNING 标志但底层驱动仍在扫描的潜在泄漏。核销成立。

### 1.4 N2 (P3)：NewDict Enter 缓冲跨详情页存活——✅ 核销成立
- **复核代码**：走查 `examples/pda2/ui_newdict.cpp`：`nd_render_detail()`（`:490`）与 `nd_tab_set()`（`:643`）两处均显式执行 `s_enter_pending = false;`，切换 Tab 或进入详情页时历史按键缓冲被及时作废。核销成立。

## 2. v1.20 NewDict 重做架构走查

本次 v1.20 按照用户诉求将应用提升至菜单首页并重构为“搜索优先 + 考试选卡”，工程实现亮点如下：

1. **共享行池复用机制（Zero-churn）**：
   - 整个页面仅创建一组 8 行按钮控件池 `s_row[PP_WB_ROWS]`（`:356`），在 Home 搜索结果、List 考试卡片列表、Exam 词书列表中动态复用；
   - 极大规避了水墨屏应用中反复清空重建子控件导致的 LVGL 堆池消耗与内存碎片。
2. **搜索交互与水墨屏纪律遵循**：
   - Home 搜索框严格遵守 EPD 静态光标要求（`bg_opa = TRANSP`，`anim_time = 0`），杜绝了输入框光标定时闪烁引发的主循环局部刷新与拖影；
   - 输入即回显，任意英数字按键在 List 状态下自动跳回 Home，交互直观顺畅。
3. **Tab 激活态的二值安全修正（v1.21）**：
   - 申请人自查将原 `LV_OPA_20` 灰底方案废除，改为选中的 Tab 采用黑底白字（反色）、未选中的 Tab 采用透明底黑字（`:409-414`）；
   - 在只有黑白两色的 E-Paper 屏幕上提供了 100% 确定性的高对比度视觉反馈，规避了灰色阈值二值化翻白丢失的硬伤。
4. **API 扩展与安全转义**：
   - `penpal_wb_list` 扩充 `exam` 参数，与 `q` 统一走 `s_urlenc()` 百分号编码，中英文考试标签均可安全构造合规 HTTP GET 请求；
   - `penpal_wb_exams` 正确解析 JSON 数组，内存申请与释放对齐。
