## 1. 变更明细

### 1.1 主菜单幽灵页（`de78338`，k3 评审 §1.1）

- **问题**：`ui_deckpro.cpp` 中 `page_num = MENU_BTN_NUM / 9` 算的是**页数**（18 项 → 2），
  但手势门控 `menu_get_gesture_dir()` 的 `if(page_curr < page_num)` 把它当**最大下标**用。
  后果：第 2 页（下标 1）再左滑，`page_curr` 增到不存在的 2 —— 翻页分支只处理
  `==0/==1`（`:303-314`），无命中、画面停在原处；且状态越界后，下一次右滑先被
  "空滑"消耗（2→1 仍显示第 2 页），用户感知为滑动失灵一次。
- **修复**：改 `(MENU_BTN_NUM - 1) / 9`（最大下标语义）：18 项 → 下标 0..1，幽灵页
  不可达；`MENU_BTN_NUM <= 9` 的单页早退（`:284`）不受影响。按钮创建循环
  （`if(i < 9) screen1 else screen2`，`:453-458`）与两枚页点（`:306-307`）不动——
  它们只与"是否 ≥2 页"相关，当前 2 页语义无变化。
- **有意不动**：Setting/Test/A7682/PCM 页是同款 `n / SETTING_PAGE_MAX_ITEM` 写法，
  但采用回绕式翻页（`(page < num) ? page+1 : 0`）且各自条目数未踩中 9 的整倍数
  （Setting 12 项、A7682 8 项等），当前无幽灵页；统一换共享 ceil helper 留给
  penpal 菜单第 3 页批次（届时主菜单也要扩 3 页/3 圆点，一并重构）。
- **台账**：issue_list 新增 §8.1（含差异描述与修复 commit）。
