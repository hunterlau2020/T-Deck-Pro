## 1. Finding

### 1.1 连接结束只清软件字符队列，阻塞期间的硬件按键仍会生效

- **严重性**：Medium
- **位置**：`examples/pda2/ui_deckpro.cpp:1640-1646`
- **触发场景**：
  1. 点击 Connect，进入最长 15 秒的阻塞连接循环。
  2. 用户在连接期间按键，事件积压于 TCA8418 硬件 FIFO。
  3. 连接结束调用 `keypad_clear_chars()`，此时这些事件尚未进入软件 FIFO。
  4. 返回主循环后 `keypad_loop()` 将硬件事件入队，输入页面随后继续消费。
- **影响**：申请宣称的“连接期间按键丢弃”没有实现，可能在连接结束后修改密码、再次提交或退出页面。
- **最小修复**：连接完成后同时丢弃硬件 FIFO 和软件字符 FIFO；不要只调用清软件队列的 `keypad_clear_chars()`。

## 2. 通过项

- 扫描覆盖层位于 top layer，能屏蔽触摸。
- 扫描期间键盘字符会被取出并忽略，不会在扫描结束后继续输入。
- 覆盖层倒计时仅在秒数变化时更新，避免每轮刷新。
- Connect 成功后才写入 NVS，失败时保留原有持久配置。
- 键盘 Enter 与触摸 Connect 使用相同连接/保存语义。
